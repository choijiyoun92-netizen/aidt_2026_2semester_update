# AIDT 2026 2학기 주요 업데이트 웹페이지 v1

## 실행 방법
1. VS Code에서 이 폴더를 엽니다.
2. `index.html`을 Live Server로 실행합니다.

## 1차 버전 범위
- 20개 Screen 기반 스토리보드 구현
- 우측 고정 내비게이션
- 우측 상단 X
- 하단 `다시 보지 않기 / CLOSE`
- 섹션별 포인트 컬러
- 15개 개선 사항 전체 반영
- 실제 이미지 미삽입 상태에서도 레이아웃 확인 가능한 Placeholder
- 이미지/GIF 파일을 `assets` 폴더에 지정 파일명으로 넣으면 자동 적용

## GIF를 특히 추천하는 개선 사항
- 01 화면 공유: 화면 공유 시작 → 학생 화면 전환
- 05 필기도구: 메모지 생성/이동/크기 변경
- 08 스스로 학습 임시저장: 확인하기 → 나가기 → 재진입 → 이어서 학습
- 10 반응형: 브라우저 크기 변화에 따라 팝업 내부 스크롤로 전환
- 11 실시간 모니터링: 화면 폭/높이에 따른 카드/표 영역 변화
- 15 화면 제어: 접힌 수업 도구의 ON/OFF 상태 변화
- 02 여러 명 리워드: 학생 복수 선택 → 일괄 지급
- 04 과제/평가: 제작 유형 탐색/선택
- 06 조회기간: 1일/1주/1개월/직접 설정 전환
- 09 출력: [출력] 클릭 → 브라우저 인쇄 화면

## 참고
GIF가 너무 무겁거나 화질이 떨어지면 mp4/webm으로 대체하는 것이 더 좋습니다.
현재 JS는 mp4/webm도 자동 재생하도록 되어 있습니다.
